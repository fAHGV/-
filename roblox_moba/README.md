# Roblox MOBA Prototype (AAA-style architecture)

Структура рассчитана под Roblox Studio с сервер-авторитативным геймплеем и data-driven контентом.

Импортируй папки в соответствующие сервисы Roblox:
- `ReplicatedStorage/*`
- `ServerScriptService/*`
- `StarterPlayer/StarterPlayerScripts/*`

Точка входа сервера: `ServerScriptService/GameServer.lua`.
